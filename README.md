# Professional Portfolio

A modern, responsive personal portfolio website built with **Next.js, React, TypeScript, and Tailwind CSS**.

The portfolio serves as a central platform for showcasing my professional background, technical skills, projects, experience, education, and contact information.

This project is also being used as a practical **DevOps and Cloud Engineering internship project**, where the focus is on applying DevOps practices to an existing web application.

---

## 📌 About the Project

This portfolio website provides a professional online presence and showcases my work, technical experience, skills, and projects.

The website includes sections for:

- Professional introduction
- About me
- Technical skills
- Projects
- Professional experience
- Education
- Contact information
- Professional and social links

The application is designed to be responsive and accessible across desktop and mobile devices.

The portfolio was initially developed and deployed using **Vercel**. It is now being used as the main application for my **DevOps & Cloud Engineering internship**, where I am applying practices such as version control, containerization, CI/CD, cloud deployment, monitoring, and documentation.
